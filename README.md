# Acne and Pimple Prediction

## Overview
This project uses **Machine Learning** to analyze lifestyle factors and predict the likelihood of acne. It studies how habits like **diet, stress, sleep, water intake, and skincare routines** influence acne occurrence.

The project performs **data analysis, classification, clustering, and association rule mining** to discover patterns related to acne.

---

## Dataset Features
The dataset includes the following factors:

- Age  
- Gender  
- Skin Type  
- Sun Exposure  
- Sunscreen Usage  
- Face Washing Habit  
- Water Intake  
- Junk Food Consumption  
- Sugar Intake  
- Stress Level  
- Family History  
- Face Touch Habit  
- Sleeping Hours  
- Current Acne Status

## Project Objectives

### 1. Identify Acne Causes
Use **Random Forest Feature Importance** to find the most important factors influencing acne.

### 2. Acne Prediction
Train multiple machine learning models to predict acne occurrence:

- Logistic Regression  
- KNN  
- Decision Tree  
- Naive Bayes  
- SVM  
- Random Forest  
- Gradient Boosting  

Models are evaluated using **Accuracy, Precision, Recall, and F1 Score**.

### 3. Acne Severity Prediction
Use **multi-class classification** to predict acne severity levels.

### 4. Skin Profile Clustering
Apply **K-Means clustering** to group people based on similar skin and lifestyle patterns.

### 5. Lifestyle Pattern Discovery
Use the **Apriori Algorithm** to discover combinations of habits strongly associated with acne.

Example insight:  
High sugar intake + High stress → Higher acne risk.
